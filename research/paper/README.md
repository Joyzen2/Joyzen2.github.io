# 中证500 指数增强模拟实盘

虚拟资金 1000 万元，从 2026-11-30 的信号开始，只往前记，不回填。每个交易日收盘后运行一次：

```bash
uv run research/paper/run.py daily
```

月末最后一个交易日运行后，会写出 `state/signals/<日期>.json`。**这个文件要在下一交易日开盘前提交并推送**：提交时间早于成交，是没有使用未来数据的证据。

## 规则

- 信号：月频 ICIR 合成，37 个因子（方法见 `enhance/README.md`）。
- 成交：信号日 T 收盘出信号，T+1 开盘成交。停牌冻结；开盘封涨停只能减不能加，封跌停只能加不能减；被冻结的权重先占住，其余按目标比例重新分配。主板、创业板 100 股一手，科创板至少 200 股。
- 成本：买卖各 0.10%（含佣金与滑点），卖出另加印花税 0.05%。
- 估值：复权价 = 东方财富不复权价 × 新浪后复权因子；除权除息日按复权因子同步股数，现金分红视为再投资。
- 基准：中证500 全收益指数 H00905，起点按价格指数的隔夜跳空近似到执行日开盘。
- 对冲：IC 空头，名义金额等于多头市值，按整数手；实际比例偏离目标超过 8% 才调整；持有剩余天数大于 20 天的最近合约；保证金按面值 15% 计，资金成本按 Shibor 3M。

全部参数在 `paper/config.py`。

## 试运行

正式开始前，可以用占位信号（按指数权重取前 80 只并封顶，没有选股能力）把整条链路跑一遍：

```bash
uv run research/paper/run.py daily --dry-run --signal benchmark --force-signal
```

试运行写入 `state-dryrun/`，不进仓库，不影响正式记录。
